# FoundationKit Security Documentation

The active security documentation describes reusable Core and Workbench boundaries only.

- `CURRENT-SECURITY-STATUS.md` — what repository evidence currently proves and what it does not.
- `THREAT-MODEL.md` — Core/Workbench threat boundaries.
- root `SECURITY.md` — reporting and repository policy.
- `docs/PRODUCTION-READINESS-AR.md` — deployment-specific production gate.

Historical application-specific evidence was removed with the retired application projects and must not be treated as current Core evidence.
