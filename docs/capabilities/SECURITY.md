# Security Capability

`FoundationKit.Security` contains reusable ASP.NET Core security conventions such as trusted reverse-proxy handling, deterministic rate-limit partition helpers, and shared MFA-assurance vocabulary.

It does not authenticate users, choose a production ingress topology, own secrets, or select deployment rate limits.

Current maturity: `Preview`. The reusable surface is implemented and quality-gated, while broader deployment compatibility remains environment-specific.
