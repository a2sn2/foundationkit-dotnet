FoundationKit

Core vNext v1

A composable .NET 10 system-building foundation with deterministic schema-v2 composition, project isolation, SQL-first read models, runtime OpenAPI, typed clients, and a first-party Core Studio reference experience.

Composer → Product

One canonical schema-v2 parser/analyzer drives deterministic project generation. The visual Composer submits to that same engine instead of maintaining browser-only manifest rules.

SQL-first Read Contracts

Generated resources use explicit filter/sort/index policy; multi-table responses and reports use product-owned SQL views with keyless read-only EF mappings.

OpenAPI → Typed Frontend

Runtime OpenAPI is the serialized transport source for deterministic Postman, C# typed clients, and an opt-in Blazor WebAssembly application shell.

Core Studio

Workbench exposes capability/module evidence, canonical manifest validation, and engineering proof while keeping authorization and business semantics on the server.

Completion Boundary

Repository completion and green CI are engineering evidence, not Production approval. External protected-main, independent-review, and go-live governance remain separate.
